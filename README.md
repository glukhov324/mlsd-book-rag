# Интуиция

RAG по книгам в формате EPUB с механизмом антиспойлера. Проект добавляет к существующему ридеру функцию вопросов по книге во время чтения.

## Какую проблему решает Интуиция

При чтении часто нужно **не выходя из книги** уточнить смысл абзаца или термина, вспомнить, кто такой персонаж, или разобраться в сложном месте. Искать ответ в интернете или в общем чате с языковой моделью неудобно и ненадёжно: ответ может **не опираться на текст вашего издания**, содержать **ошибки и домыслы**, а модель может **знать сюжет дальше по книге** и **раскрыть события, которые вы ещё не читали**.

**Интуиция** отвечает **по тексту открытой EPUB-книги** и учитывает **прогресс чтения** (и выделенный фрагмент, если пользователь его указал), чтобы **не подтягивать в ответ непрочитанную часть**. Ответ сопровождается **источниками в книге**, чтобы можно было проверить формулировку.

## Цели проекта

- отвечать на вопросы с выделенным фрагментом и без него;
- находить релевантные фрагменты гибридным поиском (dense и sparse) в тексте книги;
- не использовать непрочитанную часть книги при генерации ответа (антиспойлер);
- возвращать ответ вместе с источниками;
- сравнить vanilla и multi-query RAG с реранкингом и без него.

## Что делает пилот

Пользователь читает книгу в EPUB-ридере и задаёт вопрос одним из двух способов:

- выделяет фрагмент и спрашивает о нём;
- задаёт общий вопрос с текущей позиции чтения.

Система ищет ответ только в разрешённой части книги, возвращает его вместе с источниками и не использует ещё непрочитанный пользователем текст. После ответа пользователь оценивает полезность и наличие спойлера.

Пилот проводится на подготовленном наборе книг и вопросов. В нём используется конфигурация RAG, выбранная после сравнения четырёх вариантов.

## Сравниваемые конфигурации RAG в рамках пилота

- vanilla RAG без реранкинга (baseline для сравнения);
- vanilla RAG с реранкингом;
- multi-query RAG без реранкинга;
- multi-query RAG с реранкингом
