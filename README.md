# RAG по книгам с механизмом антиспойлера

Проект добавляет к существующему EPUB-ридеру функцию вопросов по книге. Ответ
формируется на основе RAG и учитывает прогресс чтения пользователя, чтобы не
использовать фрагменты из непрочитанной части книги.

## Цели проекта

- отвечать на вопросы с выделенным фрагментом и без него;
- находить релевантные фрагменты в тексте книги;
- ограничивать контекст текущим прогрессом чтения;
- возвращать ответ вместе с источниками;
- сравнить vanilla и multi-query RAG с реранкингом и без него.

## Что делает пилот

Пользователь читает книгу в EPUB-ридере и задаёт вопрос одним из двух способов:

- выделяет фрагмент и спрашивает о нём;
- задаёт общий вопрос с текущей позиции чтения.

Система ищет ответ только в разрешённой части книги, возвращает его вместе с
источниками и не использует непрочитанный текст. После ответа пользователь
оценивает полезность и наличие спойлера.

Пилот проводится на подготовленном наборе книг и вопросов. В нём используется
конфигурация RAG, выбранная после сравнения четырёх вариантов.

## Сравниваемые конфигурации

- vanilla RAG без реранкинга;
- vanilla RAG с реранкингом;
- multi-query RAG без реранкинга;
- multi-query RAG с реранкингом.

## Метрики

- retrieval: `Recall@10`, `Hit@10`, `MRR@10`;
- генерация: `Faithfulness`, `Answer Correctness`;
- антиспойлер: `Anti-spoiler Rate`;
- производительность: `p50` и `p95` latency.
